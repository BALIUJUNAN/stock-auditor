| A1 | 商业数据源与跨平台 | 商业源是可选插件，仅 Windows；装不上时系统照常运行；优先 HTTP，其次 SDK；无商业源时跳过交叉验证并标“未交叉验证”，不标“数据存疑”，不阻断 LLM | `DECISIONS.md` A1 |
| A2 | 公告正文 | 巨潮 PDF + `pdfplumber`；禁用 PyMuPDF（AGPL）；硬 Veto 只看标题；只为 LLM 池下载近 90 天正文，按公告编号缓存；扫描件跳过 | `DECISIONS.md` A2 |
| A3 | 问询函/纪要/新闻 | 问询函及回复按公告标题识别；纪要使用“投资者关系活动记录表”；新闻第一阶段不纳入 | `DECISIONS.md` A3 |
| A4 | 一致预期 | 过渡期用 AKShare 东方财富盈利预测，记录来源；商业源接入后优先并重跑校准；少于 3 家机构视为缺失 | `DECISIONS.md` A4 |
| A5 | Token 预算 | 中文 1 字=1 token；英文/数字 3.5 字符=1 token；加 10% 余量；记录实际用量校正；不引入 tiktoken | `DECISIONS.md` A5 |
| A6 | CAGR/PEG | FY0 为计算日已发布年报的最近财年；净利润 CAGR=(FY0+2 预测÷FY0 实际)^(1/2)−1；营收 CAGR=(FY0÷FY0−3)^(1/3)−1；PEG=PE_TTM÷(CAGR×100) | `DECISIONS.md` A6 |

## B. 算法口径（已确认）

| 编号 | 问题 | 结论摘要 | 详见 |
| --- | --- | --- | --- |
| B1 | 分位算法 | (平均排名−1)÷(n−1)，越好越接近 1；并列取平均秩；含自身；n=1 记 0.5；行业样本为非 ST、上市满 1 年、指标非空；不按换手率筛；补全值不入样本；历史少于 600 个有效交易日算不足；越小越好用 1−分位 | `DECISIONS.md` B1 |
| B2 | 停牌 | 交易日历中无日线记录或成交量为 0 算停牌；商业源标记优先 | `DECISIONS.md` B2 |
| B3 | 质押 | 控股股东（含一致行动人）质押股数÷其持股数 >70% 触发；拿不到明细不 Veto，标“质押数据不全”；不用全公司整体比例替代 | `DECISIONS.md` B3 |
| B4 | 破位 | 近 5 日内找放量跌破 MA60 日；从跌破日到今天每天收盘 <MA60 且 ≥3 天；跌破日只能在 4-2 天前；今天/昨天跌破只标“疑似破位”不扣分 | `DECISIONS.md` B4 |
| B5 | 补充池 | 关注名单优先占名额；量化池 `min(50, 75−关注名单数)`；补充池按低估值→公告→调研依次填；关注名单上限 20，超过启动报错 | `DECISIONS.md` B5 |
| B6 | 历史分位/PIT | 历史分位比自身过去，与行业无关；行业分位用计算当天划分；只影响回测；每周保存行业快照 | `DECISIONS.md` B6 |
| B7 | 财务健康度分母 | 3 年归母净利合计 ≤0 时不参与该子项排名；经营现金流合计 >0 给 2/4 分，否则 0 分；标“亏损，现金流比不适用” | `DECISIONS.md` B7 |
