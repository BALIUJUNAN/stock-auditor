## A. 数据源

### A1 商业数据源与跨平台

- 商业数据源只支持 Windows，做成可选插件。
- 跨平台要求只管核心系统：插件装不上时系统照常运行，只是缺少交叉验证。
- 优先走厂商 HTTP 接口；不行再用 SDK。iFinD 据称有 HTTP 接口，具体以 T0.3 探测结果为准。
- 只有 SDK 时，文档注明“仅支持厂商指定的操作系统”。
- 没有商业源时：交叉验证跳过，报告标“未交叉验证”；不标“数据存疑”，也不因此阻止该股进入 LLM 池。
- T0.5 验收：用离线样本模拟接口；真实对接在客户电脑上做。
- T0.7 只依赖 AKShare，不受影响。
- 已确认客户环境为 Windows；商业数据源厂商待客户购买时确定。
- T0.1-T0.4 可以照常开始。

### A2 公告正文

- 公告原文来自巨潮 PDF；依赖加 `pdfplumber`，不用 PyMuPDF（AGPL）。
- 硬 Veto 只看公告标题，不需要正文。
- 只为 LLM 池里的股票（最多 75 只）下载近 90 天公告正文；按公告编号缓存，不重复下载。
- 扫描版 PDF 没有文字可提取，直接跳过并标“无文本”，不做 OCR。

### A3 问询函、业绩说明会纪要、新闻

- 问询函和回复本身就是公告，直接从公告库按标题关键词识别，不需要单独数据源。
- 业绩说明会纪要用巨潮“投资者关系活动记录表”，这类记录表也是公告。
- 新闻第一阶段不纳入；来源不稳定、质量一般。字段保留，以后按需接入。
- `counter_checks` 找不到佐证时本来就允许填“未找到相关信息”，材料少只会让结论更保守，流程不会卡住。

### A4 一致预期

- 过渡期用东方财富盈利预测（AKShare 接口，接口名以 T0.3 探测为准）。
- 数据表记录每条预测的来源。
- 商业源接上后优先用商业源；切换后必须重新跑一次校准。
- 少于 3 家机构覆盖时视为缺失，按已有降级规则处理。

### A5 Token 预算

- 不需要精确，只保证不超预算。
- 按字符估算：中文 1 个字按 1 个 token；英文和数字 3.5 个字符按 1 个 token；再预留 10% 余量。
- 每次调用后记录模型返回的实际用量，用来修正估算比例。
- 不引入 `tiktoken`；各家模型分词方式不同，引入了也算不准。

### A6 复合增速与 PEG

- 基期 FY0：计算当天已经发布年报的最近一个财年。
- 净利润两年复合增速 = (FY0+2 预测净利润 ÷ FY0 实际归母净利润)^(1/2) − 1。
- 预测值取计算当天之前最新一份一致预期数据。
- FY0 或预测值 ≤ 0 时视为无法计算，PEG 子项记 0 分。
- PEG = 当天 PE_TTM ÷ (净利润复合增速 × 100)。
- 营收复合增速（用于对照行业下限）= (FY0 营收 ÷ FY0−3 营收)^(1/3) − 1，取自年报。
- 不足 3 年时视为不达标。
- 客户确认：可用历史数据和商用数据；营收增速倾向历史数据，因为可靠且免费源可拿；后续购买商用数据。

## B. 算法口径

### B1 分位数

- 百分位 = (平均排名 − 1) ÷ (n − 1)，按“越好排名越靠后”排序，取值 0-1。
- 并列时取平均排名；计算样本包含它自己；只有 1 个样本时记 0.5。
- 行业内比较样本：同一申万二级行业里，非 ST、上市满 1 年、该指标不为空的股票。
- 样本不按换手率筛，否则同行业对比对象会随行情变化。
- 用行业中位数补出来的值不算进样本。
- 自身历史比较：该股近 5 年日序列（含当天），同一个公式；少于 600 个有效交易日按“历史不足”处理。
- 越小越好的指标：资产负债率、应收增速减营收增速、PE/PB 历史分位；统一用 1 减去分位来计分。

### B2 停牌判定

- 用交易日历判断：某个交易日日线里没有这只股票的记录，或者成交量为 0，就算停牌。
- 商业源如果直接提供停牌标记，以商业源为准。

### B3 控股股东质押比例

- 口径：控股股东（含一致行动人）质押的股数 ÷ 他们持有的股数；超过 70% 触发一票否决。
- 拿不到控股股东明细时不触发一票否决，只标“质押数据不全”。
- 不得用全公司的整体质押比例替代，两者含义不同。

### B4 破位信号

- 找最近 5 个交易日内的放量跌破日：收盘价跌破 60 日均线，且当天成交量超过前 20 日均量的 1.5 倍。
- 确认条件：从跌破那天到今天，每天收盘都在 60 日均线下方，且总共不少于 3 天。
- 因此跌破日只能落在 4 天前到 2 天前之间。
- 今天或昨天才跌破：只标“疑似破位”，不扣分，等下一次计算时再确认。

### B5 补充池排序

- 关注名单永远优先，且先占名额。
- 量化池放 `min(50, 75 − 关注名单数量)` 只。
- 补充池按顺序填满剩余名额：
  1. 重点赛道低估值股，按基本面分从高到低。
  2. 近期重大公告，按公告日从近到远；同一天看基本面分。
  3. 机构调研活跃，按调研次数从多到少；次数相同看近 20 日涨幅，从小到大。
- 关注名单最多 20 只；超过就在启动时报配置错误。

### B6 历史分位与行业成分

- 历史分位比的是这只股票自己的过去，与行业划分无关。
- 行业内分位每次都用计算当天的行业划分。
- 唯一影响在回测，标注为已知局限。
- 每周保存一份行业划分快照，往后可还原当时口径。

### B7 财务健康度分母

- 近 3 年归母净利润合计 ≤ 0 时，这只股票不参与“经营现金流 ÷ 归母净利润”这一项的行业排名。
- 改用固定分：经营现金流合计 > 0 给 2 分（满分 4 分），否则给 0 分。
- 同时标“亏损，现金流比不适用”。
