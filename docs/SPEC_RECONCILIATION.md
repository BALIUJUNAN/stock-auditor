# 规格书对照与执行口径

- 版本：1.1
- 日期：2026-10-29
- 输入文档：
  - 《基本面选股辅助与智能审计系统 · 设计书》最终确认版（下称“设计书”）
  - 《技术实施计划书 v1.0》（下称“计划书”）
  - 《开发任务书 v1.0（给编程 agent）》（下称“任务书”）
- 用途：开发期间三份文档不一致时，按本文归并后的口径执行。本文不新增需求，只做优先级判定和口径归并。

## 1. 优先级

**任务书 > 计划书 > 设计书。**

- 任务书开头明确：“与《技术实施计划书 v1.0》冲突时以本文为准”。
- 计划书开头明确：“基于《设计书》最终确认版转化 · 已合入评审修正项”。
- 设计书虽标“最终确认版”，但内容早于评审修正，含已废弃条款（见第 3 节）。

执行顺序：

1. 任务书写了的，按任务书。
2. 任务书没写、计划书写了的，按计划书，且不得与任务书冲突。
3. 两者都没写的，按设计书；先检查是否属于第 3 节的过时章节。
4. 仍不明确，登记到 `OPEN_QUESTIONS.md`，不自行发明规则。

### 2.4 脱敏样例

来源：计划书 §7.5。

- 样例从历史候选池中挑选，高/中/低三档各 1-2 个；**不使用 7 只校准股**。
- 去掉名称、代码、产品名、管理层名字、地名、具体日期；统一称“公司 A/B/C”。
- 财务数字只给行业百分位或区间，不给绝对值。
- 业务描述泛化到“某细分领域龙头”。
- 写完后做反识别检查：让模型猜公司，能猜中就继续泛化。
- Tier-1/Tier-2 输入中不得出现“持仓”“重点关注”“客户”等字样，也不得注明入池来源。
- **Agent 只创建带说明的空模板，不编写样例内容**（任务书 §12.6）。

### 2.5 周报结构

来源：计划书 §8.1，补任务书未展开的完整周报内容。

1. 顶部提醒：本周新增 Veto / 黄牌。
2. 五星区 + 四星区（按总分排序）。
3. 黄牌观察区（原始分 ≥75 但被降级；只进完整周报）。
4. 否决池（触发项与理由）。
5. 持仓与重点关注股的本周得分变化。

卡片仍按任务书 §14.2：主卡 Top 3 + 新增 Veto 数；详情卡每只四星及以上一张；证据链放折叠面板。

### 2.6 数据保留与追踪

- 卷宗/公告全文：180 天；`filter_log`：90 天。
- 跟踪：T+20 / T+60；基准沪深 300；行业基准按 `tracking.sector_benchmarks`。
- 每月统计：各星级胜率、平均超额、Veto 股后续表现、持仓股与非持仓股得分差。

## 4. 执行口径

1. **Prompt 隔离**：`config/prompts/` 不得出现 7 只校准股的名称或代码，也不得出现任何真实股票名称/代码；测试 `tests/unit/test_prompt_leak.py` 守住。
2. **进程模型**：只有一个常驻进程 `sa serve`，内含 APScheduler 和飞书长连接；不要按计划书 §3 做独立 `feishu-bot` 进程。
3. **配置与目录**：按任务书 §1.2/§3；客户私有配置只在 `config/local/`，运行数据只在 `var/`。
4. **Stage 0**：换手率、流动性、停牌、ST、次新、板块、申万一级排除；换手率不进 Veto。
5. **硬 Veto**：只由代码触发；LLM 输出不得清零。
6. **软降级**：3 条规则；封顶 69；黄牌只进完整周报。
7. **基本面**：按任务书 §8 的子项权重；行业样本 <10 改用申万一级；缺失补全 ×0.85。
8. **动量**：按任务书 §9；过热直接 0；破位扣 10；clamp 0-20。
9. **LLM**：Tier-1 抽取 → Tier-2 打分；temperature=0；锁定模型版本；缓存按输入哈希+模型+prompt 版本；校验失败重试 2 次。
10. **校准**：`sa calibrate` 只校准 Tier-2 前景分；≥5/7 通过；2 只以上偏离则非 0 退出。
11. **流水线**：周日 S1-S8；每日核心池；财报前 7 个交易日 + 披露 T+1；文件锁防并发；`--resume` 按 `run_log.step_status` 续跑。
12. **飞书**：自建应用优先，Webhook 备用；两种通道同一 `send_card` 接口；失败重试 3 次 + `push_log` + 下次补发。
13. **交付**：跨平台；`.env`/`config/local/`/`var/` 不进 Git；`sa package` 做密钥扫描和私有数据扫描；CI 跑 Windows + Ubuntu。
