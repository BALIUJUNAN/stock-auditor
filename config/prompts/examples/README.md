# 脱敏样例模板

本目录存放人工编写的 Tier-1 / Tier-2 脱敏样例。agent 只创建空模板，不填写样例内容。

编写规则（技术实施计划书 7.5）：

- 从历史各期候选池中挑选特征典型的高 / 中 / 低三档公司，每档 1~2 家；不得使用 7 只校准股，避免测试结果自己验证自己。
- 去掉名称、代码、产品名、管理层姓名、地名和具体日期，统一称「公司 A / B / C」。
- 财务数字只给行业百分位或区间，不给绝对值。
- 业务描述泛化到「某细分领域龙头」这一层。
- 写完后做反识别检查：让模型猜是哪家公司；能猜中则继续泛化。

填写完成后，将 `tier1_example.md`、`tier2_example.md` 中的占位说明替换为样例内容。
